Tài khoản khách hàng

Đăng nhập để quản lý giỏ hàng và đặt hàng nhanh hơn.

FE này dùng chung backend với trang sản phẩm. Đăng nhập xong là token được lưu để gọi các API cart và profile trong Spring Boot.

Login POST /api/auth/login
Register POST /api/auth/register
Token Lưu localStorage để dùng lại
Quay về trang sản phẩm
